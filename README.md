# Zara – AI Smart Dining Assistant

An AI-powered smart restaurant ordering experience built with React, TypeScript, and Vite.

Zara helps restaurant customers browse menus, chat with an AI dining assistant, receive personalized food recommendations, and place collaborative table orders through a modern mobile-first interface.

---

## Features

- AI-powered dining assistant
- Personalized food recommendations
- Hinglish conversational support
- Shared table cart system
- OTP-based checkout simulation
- Mobile-first responsive design
- Smooth animations using Framer Motion
- Modern dark UI with glassmorphism styling

---

## Screens

### Welcome Screen
